# `winning-pattern`

By Human0. Perfect one user-acknowledged object (repo, file, app, skill, concept, SCW…) in its own sandboxed SCW: mine the user's context for every issue, win the easiest first, reuse each win as the harness for the next.

## What it covers

- Runs in its own SCW (sandboxed by default)
- Inputs (all three required)
- How it differs from neighbouring skills
- Procedure
- Iteration
- Rules
- Example

The full instructions are in [`SKILL.md`](SKILL.md).

In Claude or Claude Code, type `/winning-pattern` followed by your request, or describe the task in plain words and Claude loads the skill when it matches.
