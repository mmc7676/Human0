# `exam-prep`

By Human0. Build a verified Human0 Test Prep app and study-guide PDF for a certification exam from its official URL. Use for /exam-prep URL plus exam name, or any request to make exam or certification prep.

## What it covers

- 1. Effort calibration (effort-optimizer, applied per step)
- 2. Fixed subagent slate (find-subagents result)
- 3. Linktree levels (linktree-search, depth found by probe)
- 4. Pipeline
- 5. Gates (never ship past a failing one)
- 6. Report (substantial work)
- 7. Kit — fetch once per session

The full instructions are in [`SKILL.md`](SKILL.md).

## Use it

In Claude or Claude Code, type `/exam-prep` followed by your request, or describe the task in plain words and Claude loads the skill when it matches.
