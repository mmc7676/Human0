# Playing Human0 Mahjong in ChatGPT

The game is one self-contained file, `assets/mahjong.html`. It needs no internet connection and no installs, so it runs anywhere that can show a web page.

## Easiest way: just open the file
1. Save `mahjong.html` to your phone or computer.
2. Open it in your browser (Safari, Chrome, Edge, or anything else). On iPhone: open it from the Files app and tap Share → Open in Safari.
3. Pick **Beginner** and tap **Deal the tiles**.

## Inside ChatGPT (Canvas)
1. Start a new chat and attach `mahjong.html`.
2. Paste this message:
   > Open the attached mahjong.html in Canvas exactly as written. Don't change any code. Then press Preview (Run) so I can play.
3. In Canvas, tap **Preview**. The game starts on its own table.

If ChatGPT offers to "improve" or shorten the code, say no. The file has to stay exactly as it is.

## As a reusable ChatGPT "GPT" (optional, for sharing with family)
Create a GPT and upload `mahjong.html` and `SKILL.md` as knowledge files. Use these Instructions:

> You host an American Mah Jongg practice game. When the user says "play", "mahjong" or "/mahjong", open the knowledge file mahjong.html in Canvas exactly as written and preview it. Never edit the file. Answer rules questions in plain, friendly language using the "Rules quick reference" in SKILL.md. Encourage beginners to keep the Coach tab open.

## Tips for new players
- Keep the **Coach** tab open. In Beginner mode, a red dot marks a good tile to discard and green outlines mark tiles to keep.
- The **Card** tab lists every hand you can win with. Tap one to make it your goal.
- Scores and level are remembered when the browser allows it. In some previews they reset when you close the page.
