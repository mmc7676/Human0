# `topic-graph-generator`

By Human0. Generate a full-level Human0 topic pack (Topic → Concepts → Skills → Agents → MCP + lexicon) from a named topic/concept, building on existing topics, with real MCP servers verified this session.

## What it covers

- Input
- Procedure
- Output
- Boundaries
- Acceptance

The full instructions are in [`SKILL.md`](SKILL.md).

## Use it

In Claude or Claude Code, type `/topic-graph-generator` followed by your request, or describe the task in plain words and Claude loads the skill when it matches.
