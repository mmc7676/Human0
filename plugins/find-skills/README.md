# `find-skills`

By Human0. Design the optimal fixed slate of durable skills (or, with level=, of topics/concepts/agents/MCP servers) for an agent or domain, with per-level coverage, traceability and parity checks.

## What it covers

- Input
- Level model (Human0 / Context Plane Control Graph)
- Workflow
- Decision rules
- Required output
- Per-level checks (coverage-testing-artifact-parity, applied to LEVELS not artifacts)

The full instructions are in [`SKILL.md`](SKILL.md).

## Use it

In Claude or Claude Code, type `/find-skills` followed by your request, or describe the task in plain words and Claude loads the skill when it matches.
