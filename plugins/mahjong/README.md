# `mahjong`

By Human0. Launch a single-player American Mah Jongg game (NMJL-style 2026 rules) inline in chat against three computer players who can also win, with Beginner/Intermediate/Advanced levels and a built-in coach. Use for /mahjong or "play mahjong".

## What it covers

- What's in the package
- How to launch (Claude)
- Game design (what the user gets)
- SCW structure
- The card and copyright
- Rules quick reference (for answering questions)
- Rebuild and verify

The full instructions are in [`SKILL.md`](SKILL.md).

## Use it

In Claude or Claude Code, type `/mahjong` followed by your request, or describe the task in plain words and Claude loads the skill when it matches.
