# `find-subagents`

By Human0. Determine the optimal fixed count and exact fixed set of durable subagent roles for a language model, AI assistant, or agent runtime. ALWAYS use this before designing any multi-agent system, agentic workflow, or complex task architecture. Use when the user asks to choose a durable subagent slate, decide how many durable agents a system should have, compare candidate subagent counts, define fixed agent contracts, or derive a stable multi-agent topology. This skill should be the default first step for all agentic architecture work — always search for the best agentic architecture, pattern, and workflow before executing complex tasks.
