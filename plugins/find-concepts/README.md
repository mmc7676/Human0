# `find-concepts`

By Human0. Choose the optimal fixed set of 5-8 durable concepts for a topic, each with 2-4 skills' worth of scope, with coverage and traceability checks.

## What it covers

- Input
- Workflow
- Output

The full instructions are in [`SKILL.md`](SKILL.md).

## Use it

In Claude or Claude Code, type `/find-concepts` followed by your request, or describe the task in plain words and Claude loads the skill when it matches.
