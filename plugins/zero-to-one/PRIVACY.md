# Zero to One — Privacy Policy

Last updated: November 15, 2026

Zero to One is a skill-only Claude plugin. It contains instructions and reference files only: no MCP servers, no hooks, no scripts and no local code execution.

- The plugin does not collect, store, or transmit personal data.
- The plugin sends no data to any service run by Human0 or any third party.
- The plugin keeps no data between sessions.

Any web lookups made while the skill runs are performed by Claude using its own tools, under Anthropic's privacy policy (https://www.anthropic.com/legal/privacy), not by this plugin.

Questions: https://github.com/mmc7676/Human0/issues
