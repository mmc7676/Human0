# `starting-five`

By Human0. NBA Collect Starting 5 Contest: picks the max-expected Topps-rubric player at PG, SG, SF, PF and C for the current NBA slate, with live injuries, matchups, pace and blowout/back-to-back minutes. Use for /starting-five.

## What it covers

- Slate rule (no date argument)
- Step 0: load the data (works in any chat)
- Data
- Scoring rubric (matches Topps card totals exactly: Caleb Wilson 66, Walker Kessler 47, Brook Lopez 49)
- Procedure
- Model (applied to every player in every slate game)
- Output

The full instructions are in [`SKILL.md`](SKILL.md).

## Use it

In Claude or Claude Code, type `/starting-five` followed by your request, or describe the task in plain words and Claude loads the skill when it matches.
