Summary

System One is a provider-neutral semantic decision layer that works over SCWs as explicit address spaces. It selects among bounded candidate destinations (capabilities, skills, context regions, agents, tools, resources or execution paths) while staying separate from authorization and execution. Its central invariant is Decision ≠ Authorization ≠ Execution ≠ Observation: a decision grants nothing until the host admits it against identity, policy, capabilities, SCW state and provenance. The paper defines the architecture, applications, threat model, evaluation method and implementation program; no empirical performance or safety result is claimed.

Questions and answers

What does System One decide?
Which bounded destination a request should go to: a capability, skill, context region, agent, tool, resource or execution path.
What is the key invariant?
Decision ≠ Authorization ≠ Execution ≠ Observation: choosing a destination never by itself grants permission to act.
Is it tied to one model vendor?
No, it is designed to be provider-neutral.
What evidence is there?
None claimed. The paper sets out hypotheses and the method needed to test them.
